# Vejret ☀️🌧️

En simpel vejr-app, der viser vejret lige nu, de næste timer og en 7-dages
prognose. Du kan søge på en hvilken som helst by — den starter med København.

Vejrdata kommer fra [Open-Meteo](https://open-meteo.com), som er gratis og
ikke kræver nogen konto eller adgangskode.

## Sådan starter du appen

1. Installér [Node.js](https://nodejs.org) (vælg "LTS"-versionen), hvis du
   ikke allerede har det.
2. Åbn en terminal i denne mappe og skriv:

   ```sh
   npm install
   npm run dev
   ```

3. Åbn adressen, der vises (typisk `http://localhost:5173`), i din browser.
